Sistema (dimensionamiento)
Híbrido PV + Diésel (opcional) ⭐ caso de uso #1 Perú rural
El sistema busca el kWp óptimo que minimiza el costo total a 20 años (CAPEX PV + diésel residual descontado). Sin batería: PV cubre demanda diurna. Con batería: PV + batería cubren parte de la noche también.
Almacenamiento — baterías (opcional)
350 ciclos/año = uso off-grid típico (1/día). Grid-tied con respaldo: ~150–200. Temperatura promedio se toma del análisis solar (lapse rate desde forecast).
Cotización formal (BOM + propuesta cerrada) ⭐ permite cobrar 2-3× más
Precios referenciales mercado Perú 2026 (PROENERGÍA, AUTOSOLAR PERÚ, ECOSOLAR). Ajustá margen según tu mercado: 15 % bajo, 20 % estándar, 25-30 % premium. El recargo regional (+10 %) se aplica auto si el sitio es sierra o selva.

Bombeo solar agrícola (opcional)
Auto-estimar caudal desde cultivo
El kWp PV se dimensiona usando el mes crítico del análisis solar principal (con derating 0.85 + margen 10 %). Para bombeo directo (sin batería) coincidir horas con mediodía solar.
Eólico (opcional)
Datos: Open-Meteo Archive ERA5 horario (~9 km). Para topografía compleja (sierra alta) ERA5 sub-estima viento real ~10–20 %. Aproximación razonable para pre-feasibility, no para diseño final de parques.
Análisis económico
Defaults Perú 2026: residencial $1000/kWp, tarifa BT5B ~$0.135/kWh, diésel desplazado ~$1.35/kWh, utility scale $700/kWp.
Montaje del panel
Default automático: PVGIS calcula tilt y azimut óptimos para la latitud (típicamente ~lat° en Perú, mirando al norte). Sin este flag los valores asumen panel horizontal y subestiman el yield ~10–15 %.
